# Israil Mohammed — Data Analyst Portfolio

A responsive, dark-themed static portfolio built from the information in the supplied resume.

## Run locally

No build step is required.

Open `index.html` in a browser, or serve the folder with any static web server.

Example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Customize

- Personal/contact information: edit `index.html`
- Styling: edit `styles.css`
- Interactions: edit `script.js`
- Resume: replace `assets/Israil_Mohammed_Resume.pdf`
- Project links: add real GitHub/dashboard URLs when available

The sales dashboard shown is explicitly an illustrative mockup and does not represent real project metrics.
